# Almaz OS

Репозиторий содержит два основных компонента:

## 📁 Структура

```text
Almaz/
├── Alamaz OS/ # операционная система
│     ├── Almaz/ # язык программирования
│     │     ├── examples/ # примеры кода
│     │     ├── tests/ # тесты языка
│     │     ├── src/ # исходники компилятора
│     │     │    ├── compiler/
│     │     │    ├── lexer/
│     │     │    ├── parser/
│     │     │    └── stdlib/
│     │     └── Makefile
│     ├── docs/ # ИСТОРИЧЕСКИЕ ДОКУМЕНТЫ (2023)
│     │   ├── Проект(письменая часть).docx
│     │   └── Проект (презентация).pptx
│     ├── bootloader/ # загрузчик
│     ├── kernel/ # ядро
│     ├── fs/ # файловые системы
│     ├── network/ # сетевой стек
│     └── drivers/ # драйверы
├── .gitignore
└── README.md
```

## 🚀 Компоненты

### 🔵 **Alamaz OS** — операционная система

Написана на языке Almaz. Включает загрузчик, ядро, драйверы, ФС, сеть.

### 🟢 **Almaz** — язык программирования

Компилятор на ассемблере. Служит для разработки ОС и приложений под неё.

## 🎯 Цель

Создать полностью самодостаточную экосистему:

- ✅ Компилятор на ассемблере
- ✅ ОС на своём языке
- ✅ Всё вместе работает
